# 🦷 Turma do Bem — Projeto de Repaginação do Site

Projeto desenvolvido com o objetivo de modernizar e reorganizar o site da
**Turma do Bem**, uma ONG que conecta dentistas voluntários a pessoas em
situação de vulnerabilidade social, oferecendo atendimento odontológico
gratuito.

---

## 📖 Sobre o Projeto

A ONG Turma do Bem enfrenta dificuldades no gerenciamento de suas
informações — hoje ainda utiliza planilhas em Excel para controlar grandes
volumes de dados sobre colaboradores, dentistas voluntários e pacientes.

Nossa solução propõe:

- **Repaginação completa do site** (layout e informações);
- **Sistema de registro de usuários** com banco de dados integrado;
- **Centralização e organização** das informações da ONG;
- **Maior transparência** para o público externo (dentistas e beneficiários);
- **Segurança e privacidade** dos dados pessoais, acessíveis apenas por
  membros internos da ONG.

---

## 🎯 Objetivos

- Facilitar a compreensão de como a ONG funciona, seus projetos e formas de doação;
- Simplificar o processo de inscrição de dentistas voluntários;
- Centralizar dados de doadores, dentistas, colaboradores e pacientes;
- Melhorar a segurança, organização e eficiência no gerenciamento das informações;
- Oferecer uma experiência intuitiva para todos os tipos de usuários.
